A biller's CurWork session, start to finish

One customer's month goes from S3, through your usual macros, and back to S3, and nothing is left on the laptop at the end. It takes under two minutes to watch.

0:00

Space plays or pauses. The arrow keys go back or forward a step. Sample data only: the bucket, user, customers, files, sizes and macro names are made up.

Chapters

    The four steps in the CurWork window

    1. Download files from S3

    Open the customer folder and the month, select it, then click Download selected. The files go into the In folder.

    2. Run your macros as usual

    Use Copy path to paste the In folder into the macro's file box. Save results to the Out folder.

    3. Save results in S3

    Check the result type and the folder line under it, then click Save all new or changed in S3. Green means the file is saved in S3.

    4. When you're done

    Click Finish and clean up. CurWork saves today's log in S3 and empties In and Out.

    When something goes wrong

    • Press F1, or click the small ? next to any step, for help on that step.
    • Point at any button or box to see a short tip about what it does.
    • If CurWork says a file is open in Excel, save and close it, then try again.
    • If a file with the same name is already in S3, CurWork asks before replacing it.
    • If you forget to finish, CurWork reminds you about the leftover files the next time it starts.
    • To ask for help, open About, click Copy details, and paste them into your message to your admin.
